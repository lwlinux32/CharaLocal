Local Model Setup & Troubleshooting Guide

Ollama is the easiest and most popular way to run local open-source models (Llama 3, Mistral, Qwen, Gemma) on your own machine.

Step 1: Download & Run a model

In your computer's terminal (PowerShell, Terminal, or Bash):

ollama run llama3
Step 2: Allow Cross-Origin (CORS) Access

If connection is refused or blocked, launch Ollama with CORS origins allowed:

macOS / Linux terminal:

OLLAMA_ORIGINS="*" ollama serve

Windows PowerShell:

$env:OLLAMA_ORIGINS="*" ; ollama serve
Step 3: Connect in Settings
  • API Base URL: http://localhost:11434/v1
  • API Key: Leave completely blank (Ollama needs no key)
  • Model: llama3 (or click "Fetch Installed Models")

LM Studio provides a complete graphical interface with GPU acceleration to download any GGUF model and run a local OpenAI-compatible server.

Step 1: Download your model

Open LM Studio, use the Search icon on the left, and download a model (e.g. Llama-3-8B-Instruct or Mistral-7B).

Step 2: Start the Local Inference Server
  1. Click the Local Server icon (the double arrow <-> on the left navigation bar).
  2. Select your downloaded model from the dropdown at the top.
  3. In the right-side Server Settings, turn CORS ON.
  4. Click the green Start Server button (Default port is 1234).
Step 3: Connect in Settings
  • API Base URL: http://localhost:1234/v1
  • API Key: Leave blank
  • Model: local-model
⚠️ Are you viewing this app inside the Cloud Web Preview?

If the URL in your browser ends in .run.app, you are running inside a Google Cloud server container. In this cloud container, http://localhost:11434 refers to the cloud server itself, NOT your home laptop/PC!

Option A (Recommended): Run the app locally on your PC

Clone or download this codebase to your computer and run:

python run.py

Then open http://127.0.0.1:8000 in your browser. Now http://localhost:11434/v1 will connect directly to your local Ollama or LM Studio!

Option B: Expose your local model via free ngrok tunnel

If you want to keep using this cloud preview URL while serving from your home PC's GPU:

ngrok http 11434

Copy the generated https://xxxx.ngrok-free.app URL, append /v1, and paste it into the API Base URL in Settings.

Option C: Use Cloud Provider

Use Google Gemini or OpenAI in Settings, or use the built-in offline simulation mode.

Any OpenAI-compatible local inference backend works out of the box:

  • vLLM: Start with vllm serve <model> --port 8000. Base URL: http://localhost:8000/v1
  • Jan.ai: Open Jan -> Settings -> Local Server -> Turn On (Port 1337). Base URL: http://localhost:1337/v1
  • LocalAI: Default endpoint: http://localhost:8080/v1
  • Text Generation WebUI (oobabooga): Enable --api flag. Base URL: http://localhost:5000/v1
